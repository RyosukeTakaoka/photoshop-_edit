# 夜のストリートスナップ風 プリセット（Photoshop / Lightroom 用）

## 入っているファイル

| ファイル | 内容 |
|---|---|
| `NightSnap_A_Recipe.xmp` | ChatGPTのレシピの数値をそのまま入れたプリセット（黒が深く、コントラスト強め） |
| `NightSnap_B_MatteBlue.xmp` | 完成イメージ（バンド写真）に寄せたプリセット（黒が少し浮いたマットな感じ・青い影・暖かいハイライト） |
| `preview_compare.jpg` | 上から「元写真」「A」「B」の**簡易シミュレーション**（雰囲気の確認用。実際のPhotoshopの仕上がりとは少し違います） |

`.xmp` は「Camera Raw プリセット」という形式で、**Photoshop の Camera Raw フィルター**と **Lightroom（Classic / デスクトップ版）** の両方で使えます。

## 1. プリセットを読み込む（最初の1回だけ）

1. Photoshop で写真を開く
2. レイヤーを複製（Mac: ⌘+J / Windows: Ctrl+J）
3. 複製したレイヤーを右クリック →「スマートオブジェクトに変換」
4. 「フィルター」→「Camera Raw フィルター」
5. 右側のアイコン列から「プリセット」（重なった丸のアイコン）を開く
6. プリセット欄の「…」メニュー →「プロファイルとプリセットを読み込み」
7. ダウンロードした `.xmp` ファイル（A と B の両方）を選ぶ

→ プリセット一覧に **「Night Street Snap」** というグループが追加されます。

> 「読み込み」が見つからない場合は、次のフォルダに `.xmp` を直接コピーして Photoshop を再起動してください。
> - Mac：`~/Library/Application Support/Adobe/CameraRaw/Settings/`
> - Windows：`C:\Users\（ユーザー名）\AppData\Roaming\Adobe\CameraRaw\Settings\`

Lightroom Classic の場合は、左側の「プリセット」パネルの「＋」→「プリセットを読み込み」です。

## 2. プリセットを当てる

Camera Raw フィルターのプリセット一覧で **「Night Snap A - Recipe」** か **「Night Snap B - Matte Blue」** をクリックするだけです。
マウスを乗せるとプレビューが出るので、両方見比べてみてください。

## 3. ここだけは手作業（人物マスク・背景マスク）

プリセットには「全体の調整」だけが入っています。人物を明るく・背景を暗くする**マスク**は写真ごとに形が違うので、手で追加してください（レシピの「7」の工程）。

1. Camera Raw の「マスク」→「人物を選択」→ 5人全員を選ぶ
   - 露光量 +0.20 / コントラスト +5 / シャドウ +8 / 白レベル +8 / テクスチャ +4 / 彩度 +2
2. 「マスク」→「背景を選択」
   - 露光量 -0.20 / コントラスト +5 / シャドウ -10 / かすみの除去 +3 / 彩度 -8

ここがフラッシュで撮ったような「人物が浮き上がる感じ」の一番のポイントです。

## A と B の違い

完成イメージの写真を数値で調べると、**一番暗い部分が真っ黒ではなく、少し明るい紺色**になっていました（フィルム写真によくある「マット」な黒）。
レシピ（A）はトーンカーブで黒を沈めているので、完成イメージとは逆方向です。そこで B では次のように変えています。

| 項目 | A（レシピ） | B（完成イメージ寄せ） |
|---|---|---|
| トーンカーブの黒 | 0 → 0（真っ黒） | 0 → 34（黒を少し浮かせる） |
| コントラスト | +22 | +12 |
| 黒レベル | -28 | -8 |
| 色温度 | -3 | -6 |
| 影の色（カラーグレーディング） | 色相205 / 彩度12 | 色相215 / 彩度20（もう少し青く） |
| ハイライトの色 | 色相42 / 彩度12 | 色相32 / 彩度18（オレンジ寄りの暖色） |
| 中間調 | 色相30 / 彩度5 | 色相230 / 彩度4（ほんの少し寒色） |
| 自然な彩度 / 彩度 | -12 / -5 | -18 / -8 |
| 粒子 | 35 / 24 / 65 | 40 / 25 / 60 |

## 注意点

- **色温度・色かぶり補正**は JPEG / PNG 用の値（相対値）で入っています。RAW（.CR3 / .NEF / .ARW など）に当てた場合はこの2つは反映されないので、色温度を少し青い方へ手で動かしてください。
- 当てたあとも、すべてのスライダーは自由に動かせます。顔が暗い・明るすぎるなど、写真に合わせて微調整してください。
- 粒子は**100%表示**で確認するのがおすすめです。
