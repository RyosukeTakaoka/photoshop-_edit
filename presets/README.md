# 夜のストリートスナップ風 プリセット（Photoshop / Lightroom 用）

## 入っているファイル

| ファイル | 内容 |
|---|---|
| `NightSnap_C_MatchEdit.xmp` | **おすすめ。** 元写真と完成イメージ（編集後の写真）を比べて、色と明るさの変化を測って作ったプリセット |
| `NightSnap_A_Recipe.xmp` | ChatGPTのレシピの数値をそのまま入れたプリセット（比較用） |
| `preview_compare.jpg` | 上から「元写真」「C を当てた簡易シミュレーション」「完成イメージ」 |

`.xmp` は「Camera Raw プリセット」という形式で、**Photoshop の Camera Raw フィルター**と **Lightroom（Classic / デスクトップ版）** の両方で使えます。

## 1. プリセットを読み込む（最初の1回だけ）

1. Photoshop で写真を開く
2. レイヤーを複製する（Mac: ⌘+J / Windows: Ctrl+J）
3. 複製したレイヤーを右クリック →「スマートオブジェクトに変換」
4. 「フィルター」→「Camera Raw フィルター」
5. 右側のアイコン列から「プリセット」（重なった丸のアイコン）を開く
6. プリセット欄の「…」メニュー →「プロファイルとプリセットを読み込み」
7. ダウンロードした `.xmp` ファイルを選ぶ

→ プリセット一覧に **「Night Street Snap」** というグループが追加されます。

> 「読み込み」が見つからない場合は、次のフォルダに `.xmp` を直接コピーして Photoshop を再起動してください。
> - Mac：`~/Library/Application Support/Adobe/CameraRaw/Settings/`
> - Windows：`C:\Users\（ユーザー名）\AppData\Roaming\Adobe\CameraRaw\Settings\`

Lightroom Classic の場合は、左側の「プリセット」パネルの「＋」→「プリセットを読み込み」です。

## 2. プリセットを当てる

Camera Raw フィルターのプリセット一覧で **「Night Snap C - Match Edit」** をクリックします。

## 3. ここだけは手作業（人物マスク・背景マスク）

プリセットには「写真全体の調整」だけが入っています。人物を明るくして背景を暗くする**マスク**は写真ごとに形が違うので、手で追加してください。

1. Camera Raw の「マスク」→「人物を選択」→ 5人全員を選ぶ
   - 露光量 +0.15 / シャドウ +8 / 白レベル +8
2. 「マスク」→「背景を選択」
   - 露光量 -0.30 / シャドウ -10 / 彩度 -8

C を当てただけだと、完成イメージより**水面が少し明るめ**になります。背景マスクで暗くすると近づきます。

## C で何をしているか

元写真と完成イメージを比べると、主に次の3つが違っていました。

1. **黒が浮いている**：元写真の一番暗いところは真っ黒に近いですが、完成イメージでは少し明るい紺色になっています（フィルム写真によくある「マット」な黒）。
2. **全体が青い**：元写真は街灯のせいで黄色っぽい色をしていますが、完成イメージでは影や中間の明るさの部分が青寄りになっています。
3. **明るい部分が少し抑えられている**：一番明るいところが真っ白になりすぎないようにしてあります。

C ではこれを主に **トーンカーブ** で再現しています。

- 「RGB」カーブ：黒を持ち上げて（0 → 26）、白を少し下げる（255 → 246）
- 「レッド」カーブ：暗い〜中間の赤を減らす → 黄色っぽさが消える
- 「ブルー」カーブ：暗い〜中間の青を増やす → 影が青くなる

ほかには、粒子（30）、軽い周辺減光（-10）、明瞭度 -5（少し柔らかく）を入れています。

## 微調整のコツ

- **もっと青くしたい** → トーンカーブの「ブルー」で、真ん中あたりの点を少し上に動かす
- **黒をもっと締めたい** → 「RGB」カーブの左下の点（0, 26）を少し下げる
- **水面の金色を強くしたい** → カラーグレーディングの「ハイライト」の彩度を 10 → 20 くらいに上げる
- 粒子は**100%表示**で確認してください

## 注意点

- 比較画像は Python で作った**簡易シミュレーション**なので、Photoshop で当てた結果とは少し違います。
- 完成イメージは、AI で作り直された画像のようです（例：Tシャツの「EntranCE」の文字が崩れています）。AIは細かい部分まで描き直しているので、スライダー操作で**完全に同じ**にはなりません。色や明るさの雰囲気を近づけるためのプリセットだと考えてください。
